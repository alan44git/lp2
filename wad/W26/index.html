B.E. Course Structure

This mobile site shows a simple year-wise course structure for the Bachelor of Engineering program at PICT.

FE - First Year Engineering

  • Engineering Mathematics I

    Basic calculus, matrices, differential equations, and engineering applications.

  • Engineering Physics

    Fundamentals of optics, waves, semiconductors, and modern physics.

  • Engineering Chemistry

    Study of materials, water technology, corrosion, and applied chemistry.

  • Basic Electrical Engineering

    Introduction to electrical circuits, machines, and power systems.

  • Programming and Problem Solving

    Basic programming concepts, logic building, and problem-solving techniques.

SE - Second Year Engineering

  • Data Structures

    Arrays, stacks, queues, linked lists, trees, graphs, and searching techniques.

  • Object Oriented Programming

    Classes, objects, inheritance, polymorphism, and exception handling.

  • Computer Organization

    Processor architecture, memory organization, instruction cycles, and I/O systems.

  • Discrete Mathematics

    Logic, sets, relations, functions, graphs, and combinatorics.

  • Database Management Systems

    Relational databases, SQL queries, normalization, and transactions.

TE - Third Year Engineering

  • Web Application Development

    HTML, CSS, JavaScript, server-side programming, and web application basics.

  • Computer Networks

    Network models, protocols, IP addressing, routing, and network security basics.

  • Design and Analysis of Algorithms

    Algorithm design techniques, complexity analysis, greedy method, and dynamic programming.

  • Operating Systems

    Processes, threads, memory management, file systems, and scheduling algorithms.

  • Artificial Intelligence

    Search techniques, knowledge representation, machine learning basics, and AI applications.

BE - Final Year Engineering

  • Machine Learning

    Supervised learning, unsupervised learning, model training, and prediction techniques.

  • Cloud Computing

    Cloud models, virtualization, deployment services, and distributed computing concepts.

  • Cyber Security

    Security threats, cryptography, authentication, network security, and safe computing.

  • Project Work

    Major project development using software engineering and implementation skills.

  • Elective Subjects

    Advanced subjects selected based on interest and specialization area.
